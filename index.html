SOC137

Macro-Enabled Malware Download

Malware True Positive T1204

Macro-enabled .docm file contained AutoOpen macro invoking PowerShell to download second-stage payload. Endpoint security blocked execution before C2 communication.

C2 Reached
No
Verdict
Malicious

File: INVOICE PACKAGE LINK TO DOWNLOAD.docm (16.66 KB)

Source: 172.16.17.37 (internal network)

Device Action: Blocked

Investigation: File hash analysis in VirusTotal flagged the document as malicious. Macro extraction revealed NewMacros.bas using Shell.Application to invoke PowerShell with encoded command. Network logs showed no outbound connection attempts.

MITRE ATT&CK: T1204 (User Execution), T1059 (Command and Scripting Interpreter)

Remediation: Document quarantined. Endpoint contained. No further user education recommended (blocked at mail gateway).

SOC119

Legitimate Software Download

Proxy Alert False Positive T1204

Proxy alert for executable download. Investigation revealed legitimate WinRAR download from official source. No malicious activity.

Verdict
Legitimate
Action
Whitelist

User: Susie

Host: SusieHost (172.16.17.5)

Destination: win-rar.com (official domain)

Investigation: URL reputation check confirmed official WinRAR website. File signature matched legitimate software. User had legitimate business need for the tool.
